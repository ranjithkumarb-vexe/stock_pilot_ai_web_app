# Frontend task board

Legend: status ∈ `todo · in_progress · blocked · partial · done · deferred`. `Dep` = must be `done` first. Backend tasks are in the backend repo (`stock_pilot_ai_backend_service/docs/workflow/TASKS.md`); cross-repo deps are written `BE:BE-03`.
**Source of truth for UI**: `design/StockPilot AI.dc.html` (+ `design/sp-data.js`, `design/sp-motion.js`, `design/StockPilot Design System.dc.html`, screenshots `design/Part 1.png`, `Part 2.png`). Template syntax: `<sc-if value="{{ x }}">`, `{{ expr }}`, `style-hover`, `data-m` motion attrs; logic in the trailing `<script type="text/x-dc">` class (`renderVals`, `calc`, `check`, `exec`, `pq`, `propInfo`, …) — port the *behaviour* to typed code backed by the API; the mock math now lives in the backend.
Stack decision (ADR-001): **Vite + React 18 + TypeScript (strict) + React Router + TanStack Query**, plain CSS variables from the design (no UI kit), `lightweight-charts@4.2.0`, `motion@11`.
